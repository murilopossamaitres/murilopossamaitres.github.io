Política de Privacidade — Contatos Familia

Aplicativo pessoal de Murilo Possamai Tres para os contatos da própria família

Última atualização: 26/11/2026

Quem é o responsável

Contatos Familia é um aplicativo pessoal de OAuth do Google, no projeto Google Cloud contatos-familia. Ele é usado somente por Murilo Possamai Tres para ler e organizar os contatos da própria família no Google Contatos. O acesso à conta Google é feito pela integração Composio.

Responsável pelo aplicativo e por esta política: Murilo Possamai Tres. Contato: mpossamaitres@gmail.com.

Quais dados são acessados

O aplicativo acessa os Google Contatos pela Google People API, com o escopo contacts (https://www.googleapis.com/auth/contacts). Os dados lidos são:

  • nomes;
  • números de telefone;
  • endereços de e-mail.

Para padronizar os telefones, o aplicativo pode atualizar o formato dos números que já estão nesses contatos. Não são solicitados outros dados da Conta Google, como arquivos do Drive, e-mails do Gmail, calendário, fotos ou localização.

Para que os dados são usados

O uso é exclusivamente pessoal e familiar:

  • padronizar o formato dos números de telefone;
  • fazer uma verificação semanal de consistência, inclusive para identificar contatos duplicados.

Os dados não são usados para publicidade, perfil comercial, avaliação de crédito ou qualquer outra finalidade.

Compartilhamento

Os dados dos contatos não são vendidos e não são compartilhados com terceiros, além da integração Composio usada para o acesso. A Composio é o meio técnico que conecta o aplicativo à conta Google e à Google People API. Não há cessão desses dados a anunciantes, corretores de dados ou outros aplicativos.

Publicidade

O aplicativo não usa esses dados para anúncios, publicidade personalizada, remarketing ou medição de publicidade.

Política de dados do usuário das APIs do Google, inclusive Limited Use

O uso e a transferência, para qualquer outro aplicativo, das informações recebidas das APIs do Google obedecem à Google API Services User Data Policy, inclusive os requisitos de Limited Use (Uso Limitado).

Em particular:

  • os dados servem apenas ao recurso voltado ao usuário: organizar os contatos da família, padronizando telefones e conferindo consistência e duplicatas;
  • os dados não são vendidos nem transferidos a terceiros, exceto o que for necessário para essa função, por meio da Composio, com o consentimento de quem autoriza o acesso, ou quando a lei ou a segurança exigirem;
  • seres humanos não leem esses dados, exceto o próprio titular, Murilo Possamai Tres, que autorizou o acesso à própria conta, ou quando for preciso para segurança, para cumprir a lei, ou em forma agregada e anonimizada para operação interna;
  • os dados não são usados nem transferidos para veicular anúncios, inclusive publicidade personalizada ou baseada em interesses;
  • os dados não são usados para avaliar capacidade de crédito nem para empréstimos.

Declaração na forma pedida pela política do Google: the use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Como revogar o acesso

O acesso pode ser retirado a qualquer momento na página de permissões da Conta Google: https://myaccount.google.com/permissions. Ao remover Contatos Familia dessa lista, o aplicativo deixa de acessar os contatos. A revogação não apaga os contatos que continuam na conta Google.

English summary

Contatos Familia is a personal Google OAuth application (Google Cloud project contatos-familia) used only by Murilo Possamai Tres to read and organize his own family’s Google Contacts through Composio.

Data accessed. Names, phone numbers, and email addresses from Google Contacts, via the Google People API, using the contacts scope (https://www.googleapis.com/auth/contacts). The app may update phone numbers already stored on those contacts so the format is consistent. It does not request other Google account data.

Purpose. Personal and family use only: standardizing phone-number formats and running a weekly consistency check, including looking for duplicates. The data is not used for advertising, commercial profiling, or credit decisions.

Sharing. Contact data is not sold and is not shared with third parties beyond the Composio integration used to access the Google account. It is not given to advertisers or other apps.

Google API Services User Data Policy. The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Data is used only to provide the user-facing contact-organization feature. It is not sold. It is not used for advertising, including personalized or interest-based advertising, or to determine creditworthiness. Humans do not read it except the account holder who authorized access to his own account, or as required for security, to comply with the law, or in aggregated and anonymized form for internal operations.

Revoke access. https://myaccount.google.com/permissions
